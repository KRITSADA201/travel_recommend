# ระบบแนะนำสถานที่ท่องเที่ยวตามความสนใจของผู้ใช้ กรณีศึกษาจังหวัดอุบลราชธานี
**User Interest-Based Travel Recommendation System: A Case Study of Ubon Ratchathani Province**

เว็บแอปพลิเคชันระบบแนะนำสถานที่ท่องเที่ยวในจังหวัดอุบลราชธานี พัฒนาด้วยภาษา Python และ Flask Framework ออกแบบตามสถาปัตยกรรม MVC มีระบบจัดอันดับสถานที่ยอดนิยมด้วย Multi-Tier Ranking Algorithm และคำนวณระยะทางจากพิกัดตำแหน่งจริงด้วย Haversine Formula พร้อมระบบนำทางผ่าน Google Maps แบบเรียลไทม์

## ✨ ฟีเจอร์เด่นของระบบ (Features)

### 1. ระบบแนะนำและค้นหาสถานที่ท่องเที่ยว
- **Multi-Tier Ranking Algorithm:** จัดอันดับสถานที่ยอดนิยมในหน้าแรกอย่างชาญฉลาด โดยพิจารณาจากคะแนนดาวเฉลี่ยสูงสุด (Tier 1) และจำนวนรีวิว (Tier 2)
- **ระบบคำนวณระยะทางจริง (Haversine Formula):** คำนวณระยะห่างจากพิกัด GPS ปัจจุบันของผู้ใช้ไปยังสถานที่ท่องเที่ยว และแนะนำสถานที่ท่องเที่ยว/ที่พักใกล้เคียง
- **ระบบแผนที่และนำทาง:** แสดงแผนที่พิกัด และมีปุ่มเปิดระบบนำทาง Google Maps แบบเรียลไทม์
- **ค้นหาและคัดกรองตามหมวดหมู่:** คัดกรองสถานที่ตามหมวดหมู่ความสนใจ (ธรรมชาติ, วัด, คาเฟ่, ที่พัก) และค้นหาตามคำสำคัญ

### 2. ข้อมูลสถานที่และแกลเลอรีรูปภาพ
- **รองรับหลายรูปภาพต่อสถานที่ (Multi-Image Gallery):** แสดงภาพสไลด์ พร้อมคำบรรยายภาพ (Caption)
- **ระบบแปลงภาพ Google Drive / OneDrive อัตโนมัติ (Image Proxy):** วางลิงก์รูปภาพจาก Google Drive หรือ OneDrive ระบบจะแปลงเป็นภาพแสดงผลบนเว็บให้อัตโนมัติ

### 3. ระบบสมาชิกและความปลอดภัย
- **การเข้าสู่ระบบหลากหลายช่องทาง:** รองรับ Username, Email หรือ เบอร์โทรศัพท์ ในช่องเดียว
- **Google OAuth 2.0:** เข้าสู่ระบบด้วยบัญชี Google ได้สะดวกรวดเร็ว พร้อมระบบสลับบัญชี (`select_account`)
- **ระบบลืมรหัสผ่าน (Forgot & Reset Password):** ระบบส่งลิงก์รีเซ็ตรหัสผ่านแบบ Token ปลอดภัย (มีอายุการใช้งาน 1 ชั่วโมง)
- **การรักษาความปลอดภัย:** รหัสผ่านเข้ารหัสแฮชด้วย Bcrypt และมีระบบ Session Protection ด้วย Flask-Login

### 4. ชุมชนและการมีส่วนร่วม
- **ระบบรีวิวและให้คะแนน (Rating & Reviews):** ให้คะแนนดาว 1-5 ดาว พร้อมพิมพ์ข้อความรีวิว
- **ระบบตอบกลับรีวิว (Review Reply):** ผู้ใช้และแอดมินสามารถตอบกลับความคิดเห็นใต้รีวิวได้
- **ระบบสถานที่โปรด (Favorites):** กดบันทึกสถานที่ที่สนใจเพื่อเปิดดูย้อนหลังได้จากหน้าโปรไฟล์

### 5. ระบบจัดการสำหรับผู้ดูแลระบบ (Admin Dashboard)
- **แดชบอร์ดภาพรวม:** ตรวจสอบจำนวนผู้ใช้งาน สถานที่ท่องเที่ยว และหมวดหมู่ในระบบ
- **จัดการสถานที่และหมวดหมู่:** เพิ่ม แก้ไข และลบสถานที่ท่องเที่ยวและหมวดหมู่ได้
- **จัดการผู้ใช้งาน (User Management):** ลบผู้ใช้งานที่ไม่เหมาะสม พร้อมระบบ Cascade Delete ลบรีวิวและรายการโปรดที่เกี่ยวข้องออกอย่างปลอดภัย

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
- **Backend:** Python 3.10+, Flask Framework
- **ORM & Database:** Flask-SQLAlchemy, SQLite (Development), PostgreSQL (Production)
- **Authentication & Security:** Flask-Login, Flask-Bcrypt, Google OAuth 2.0
- **Frontend:** HTML5, CSS3, JavaScript (ES6+), Bootstrap 5.3, Bootstrap Icons
- **APIs & Services:** Google Maps Embed API, Google Identity Services
- **Deployment:** Render.com, Gunicorn WSGI Server

## 🚀 วิธีการติดตั้งและรันบนเครื่อง Local

### 1. ติดตั้ง Dependencies
```bash
pip install -r requirements.txt
```

### 2. คัดลอกและตั้งค่า Environment Variables
```bash
cp .env.example .env
```
*(แก้ไขไฟล์ `.env` ใส่ค่าคีย์ความลับ เช่น `SECRET_KEY`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`)*

### 3. รันแอปพลิเคชัน
```bash
python app.py
```
เปิดเบราว์เซอร์ไปที่: `http://127.0.0.1:5000`
